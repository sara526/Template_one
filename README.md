# Leon Template One

A responsive landing page built with HTML5 and CSS3 as one of my early web development learning projects.

🔗 **[Live Demo](https://sara526.github.io/Template_one/)**

> **Learning Project:** This repository documents an early stage of my learning journey while studying HTML and CSS through Elzero Web School.

---

## 📌 About The Project

Leon Template One is a multi-section creative agency landing page created to practice the fundamentals of HTML and CSS.

The project includes several common website sections such as:

- Header & Navigation
- Landing Section
- Features
- Services
- Portfolio
- About
- Contact
- Footer

The main purpose of this project was not to create a production-ready website, but to apply the HTML and CSS concepts I was learning through a complete webpage.

---

## 🎯 Learning Objectives

Through this project, I practiced:

- Structuring webpages using HTML5
- Creating navigation links between sections
- Building layouts with CSS Flexbox
- Building responsive layouts with CSS Grid
- Using CSS Media Queries
- Creating and using CSS Variables
- Working with `position`, `z-index`, and `calc()`
- Using pseudo-classes such as `:hover`, `:first-child`, and `:nth-child()`
- Creating decorative elements with `::before` and `::after`
- Using CSS transitions
- Working with responsive images
- Creating reusable layout patterns
- Managing typography, spacing, colors, and backgrounds
